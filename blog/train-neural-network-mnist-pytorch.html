How to Train a Neural Network from Scratch with PyTorch

PyTorch Deep Learning Tutorial

Training a neural network sounds intimidating, but the core loop is surprisingly simple: forward pass, compute loss, backward pass, update weights. In this tutorial, we'll build a neural network from scratch using PyTorch and train it to recognize handwritten digits from the MNIST dataset — the "Hello World" of deep learning.

By the end of this post, you'll have a model that achieves over 98% accuracy, and more importantly, you'll understand every line of code.

What is MNIST?

MNIST is a dataset of 70,000 handwritten digits (0–9), each stored as a 28×28 grayscale image. It's been the standard benchmark for image classification since the late 1990s. The dataset is split into 60,000 training images and 10,000 test images.

Every deep learning framework includes MNIST out of the box, which makes it perfect for learning — no data wrangling required.

Prerequisites

You'll need Python 3.8+ and PyTorch installed:

pip install torch torchvision

That's it. No GPU required — MNIST is small enough to train on a CPU in under a minute.

Step 1: Load the Data

PyTorch's torchvision library handles downloading and loading MNIST. We use DataLoader to batch the data for training:

import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import datasets, transforms
from torch.utils.data import DataLoader

# Transform: convert images to tensors and normalize
transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.1307,), (0.3081,))
])

# Download and load the data
train_dataset = datasets.MNIST(
    root='./data', train=True, download=True, transform=transform
)
test_dataset = datasets.MNIST(
    root='./data', train=False, download=True, transform=transform
)

train_loader = DataLoader(train_dataset, batch_size=64, shuffle=True)
test_loader = DataLoader(test_dataset, batch_size=1000, shuffle=False)

A few things to note:

  • ToTensor() converts the PIL image to a PyTorch tensor and scales pixel values from [0, 255] to [0, 1].
  • Normalize((0.1307,), (0.3081,)) applies the MNIST dataset's mean and standard deviation — this helps the network train faster.
  • batch_size=64 means we process 64 images at a time. This is a balance between speed and memory.
  • shuffle=True for training ensures the model doesn't memorize the order of examples.

Step 2: Define the Network

We'll build a simple feedforward neural network with two hidden layers. Nothing fancy — just enough to understand the architecture:

class NeuralNetwork(nn.Module):
    def __init__(self):
        super().__init__()
        self.flatten = nn.Flatten()
        self.layers = nn.Sequential(
            nn.Linear(28 * 28, 256),
            nn.ReLU(),
            nn.Linear(256, 128),
            nn.ReLU(),
            nn.Linear(128, 10)
        )

    def forward(self, x):
        x = self.flatten(x)
        return self.layers(x)

model = NeuralNetwork()
print(model)

Let's break down what each layer does:

  • Flatten — converts the 28×28 image into a flat vector of 784 values.
  • Linear(784, 256) — first hidden layer with 256 neurons. Each neuron is a weighted sum of all 784 inputs.
  • ReLU — activation function. Replaces negative values with zero. Without this nonlinearity, stacking linear layers would just be one big linear layer.
  • Linear(256, 128) — second hidden layer with 128 neurons.
  • Linear(128, 10) — output layer. 10 neurons, one per digit class (0–9). The highest value is the model's prediction.

Step 3: Set Up the Training Loop

We need two things: a loss function to measure how wrong the model is, and an optimizer to update the weights:

criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)

CrossEntropyLoss is the standard loss for classification. It combines softmax (converting raw scores to probabilities) and negative log-likelihood into one efficient operation.

Adam is the most popular optimizer. It adapts the learning rate for each parameter, which usually converges faster than plain SGD. The learning rate lr=0.001 is a safe default.

Step 4: Train the Model

This is where the magic happens. The training loop repeats four steps for every batch: forward pass, compute loss, backward pass, update weights.

def train(model, train_loader, criterion, optimizer, epoch):
    model.train()
    running_loss = 0.0

    for batch_idx, (images, labels) in enumerate(train_loader):
        # 1. Forward pass
        outputs = model(images)

        # 2. Compute loss
        loss = criterion(outputs, labels)

        # 3. Backward pass (compute gradients)
        optimizer.zero_grad()
        loss.backward()

        # 4. Update weights
        optimizer.step()

        running_loss += loss.item()

    avg_loss = running_loss / len(train_loader)
    print(f"Epoch {epoch}: Average Loss = {avg_loss:.4f}")

The critical line most beginners miss is optimizer.zero_grad(). PyTorch accumulates gradients by default (useful for some advanced techniques), so we need to reset them before each backward pass. Forgetting this leads to exploding gradients and a model that never learns.

Step 5: Evaluate the Model

After each epoch, we check accuracy on the test set — data the model has never seen:

def test(model, test_loader):
    model.eval()
    correct = 0
    total = 0

    with torch.no_grad():
        for images, labels in test_loader:
            outputs = model(images)
            _, predicted = torch.max(outputs, 1)
            total += labels.size(0)
            correct += (predicted == labels).sum().item()

    accuracy = 100 * correct / total
    print(f"Test Accuracy: {accuracy:.2f}%")
    return accuracy

model.eval() switches off dropout and batch normalization behavior (we don't have those here, but it's a good habit). torch.no_grad() disables gradient computation — we don't need gradients for evaluation, and this saves memory and speeds things up.

Step 6: Put It All Together

# Train for 5 epochs
for epoch in range(1, 6):
    train(model, train_loader, criterion, optimizer, epoch)
    test(model, test_loader)

Don't lose your trained model — save the weights:

The Complete Code

Here's everything in one script you can copy and run:

import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import datasets, transforms
from torch.utils.data import DataLoader


# --- Data ---
transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.1307,), (0.3081,))
])

train_dataset = datasets.MNIST('./data', train=True, download=True, transform=transform)
test_dataset = datasets.MNIST('./data', train=False, download=True, transform=transform)

train_loader = DataLoader(train_dataset, batch_size=64, shuffle=True)
test_loader = DataLoader(test_dataset, batch_size=1000, shuffle=False)


# --- Model ---
class NeuralNetwork(nn.Module):
    def __init__(self):
        super().__init__()
        self.flatten = nn.Flatten()
        self.layers = nn.Sequential(
            nn.Linear(28 * 28, 256),
            nn.ReLU(),
            nn.Linear(256, 128),
            nn.ReLU(),
            nn.Linear(128, 10)
        )

    def forward(self, x):
        x = self.flatten(x)
        return self.layers(x)


model = NeuralNetwork()
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)


# --- Training ---
for epoch in range(1, 6):
    model.train()
    running_loss = 0.0

    for images, labels in train_loader:
        outputs = model(images)
        loss = criterion(outputs, labels)

        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

        running_loss += loss.item()

    # Evaluate
    model.eval()
    correct = 0
    total = 0
    with torch.no_grad():
        for images, labels in test_loader:
            outputs = model(images)
            _, predicted = torch.max(outputs, 1)
            total += labels.size(0)
            correct += (predicted == labels).sum().item()

    accuracy = 100 * correct / total
    avg_loss = running_loss / len(train_loader)
    print(f"Epoch {epoch}: Loss={avg_loss:.4f}, Accuracy={accuracy:.2f}%")


# --- Save ---
torch.save(model.state_dict(), 'mnist_model.pth')
print("Model saved.")

What Next?

Once you're comfortable with this, try these challenges to level up:

  • Add dropout — insert nn.Dropout(0.2) between layers to prevent overfitting.
  • Use a CNN — convolutional neural networks reach 99%+ on MNIST because they understand spatial patterns.
  • Try Fashion-MNIST — a drop-in replacement with clothing images instead of digits. Harder, same format.
  • Add a learning rate scheduler — reduce the learning rate as training progresses for finer convergence.
  • Visualize predictions — use matplotlib to see which digits the model gets wrong and why.

The fundamentals you learned here — data loading, model definition, training loop, evaluation — are the same whether you're training on MNIST or building a state-of-the-art vision model. The loop doesn't change. Only the model and data do.
