# Website presentation guidelines

Content, titles, menu labels, menu order, section order, links and image choices remain those in the latest committed version. Any content change requires explicit permission. Do not add portrait graphics, replacement identity marks or editorial copy beyond the explicitly approved changes below.

The redesign changes presentation: white space, responsive grids, typography, neutral surfaces, button styling, touch-friendly controls and restrained motion.

Use `#19243F` as the accent color. Use white and cool neutral gray surfaces, charcoal text and readable supporting text. Dark mode uses neutral black and charcoal surfaces, retaining navy action buttons with white labels and a visible neutral border.

Keep the original navigation sequence: Home, Courses, Services, Research, Projects, Events, About. The mobile shortcut bar follows that sequence; the full menu retains every original destination.

Retain the original homepage sequence: introduction and portrait, research, and the original profile pathways. Preserve all supplied image files. The approved background-removed light and dark portraits are used on Home and About, at a moderate desktop size and the same 16:9 mobile image-box dimensions as the other main pages. Both have the approved researcher · lecturer · creator caption. Apply no decorative overlays or color filters.

Use the shared typography scale in refinements.css: 19-pixel desktop body text, 18-pixel mobile body text, 15-pixel supporting labels, larger headings and navigation. Mobile hero actions stack vertically, with the primary button at full width and the secondary action below.

Repeated gallery previews use a 16:9 aspect ratio and 16-pixel corners. Standard records within a collection share card width and height; preserve complete text. Featured records retain the same card geometry and carry a small Featured label. The approved highlights are the ADOS-2 multimodal framework paper, Automated Detection of Play Behavior, Real-Time Social Interaction with Furhat, and PhD Public Defense. The two featured papers lead the homepage in that order. Use the explicitly supplied covers in assets/images/research, the original poster-group photo for Automated Detection, and the existing presentation photos for the papers the user asked to keep. Repeated discovery cards use the same horizontal rail on desktop and phones, with a visible next-card edge. Position indicators and identical outline arrow buttons sit above the cards, beside the heading where possible. All projects and events remain accessible in one rail, with filters and sorting preserved. Keep keyboard access and full authored text. If an event has no preview, use a neutral outline calendar symbol and No preview; never invent imagery. Keep 24-pixel phone gutters, visible focus, accessible contrast, and reduced-motion support.
